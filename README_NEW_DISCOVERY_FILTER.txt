LIVE SITE UPGRADE
1. Download this ZIP and Extract All.
2. Open the extracted folder. Select ALL the contents (not the outer folder).
3. Upload via GitHub > hidden-opportunity-vault > Add file > Upload files.
4. Commit changes to main. Existing agent/data scan-history files are NOT included, so history is preserved.
5. Actions > Daily Discovery Agent > Run workflow (main).
6. Refresh the hosted site, open Daily Agent, Load Latest Report.

VERY IMPORTANT
The existing generated agent/data files are intentionally NOT included in this ZIP. The GitHub workflow re-screens stored leads and eliminates old generic candidates after a scan. Public website records saved solely in a browser are still local to that browser, not shared with all visitors.

KNOWN LIMITATION: JavaScript-only and access-restricted websites cannot be reliably searched by a standard-library GitHub script. Source errors remain visible for review; this update improves candidate relevance, not universal source access.
