LIMITATIONS — READ BEFORE SELLING:
  - The scanning system is NOT a general AI web search or complete world scan.
    It monitors a limited set of configured sources, and access restrictions,
    anti-bot pages or JavaScript-only sites may still produce limited coverage.
  - A technically successful scan does NOT prove every source succeeded.
  - Newly extracted directory links are UNVERIFIED, may be old, and must have
    eligibility, deadline, provider and availability checked manually.
  - Admin approvals in the browser are stored LOCALLY on that browser;
    they are not globally published for all visitors automatically.
  - The existing public catalogue may contain outdated program details:
    confirm current terms against official websites.
  - The GitHub Actions schedule is a target; executions can be delayed.
  - This update has passed offline tests and browser QA; a new live GitHub
    run is still necessary to validate network-source performance.
